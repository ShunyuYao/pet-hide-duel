# 2.0.1 · 躲猫猫独立公开版

统一维护的 2D / 3D 正面玩偶版，包含自己躲藏移动和准星的流畅度修复。

- `pet-hide-duel.html`：在兼容桌宠中发送并一起玩。
- `pet-hide-duel-lan.zip`：解压后运行局域网启动器，普通浏览器可上传 2D 图片对战；房主需 Node.js 22+。
- `SHA256SUMS.txt`：下载文件校验值。

已通过 75 项核心/网络/服务测试与 2D、3D 隐藏真实双实例投递、邀请、操作和离开验证。HTML 内附完整第三方许可，不含私人照片、角色包或宿主安装文件。

已知边界：射击方在洞口看见的对方碎片仍随快照刷新，可能跳动。两台物理电脑、Windows 原生启动和公网联机未验证。两端使用同一版本；3D 需要兼容宿主和玩家自己的玩偶素材。

## English

The unified 2D / frontal 3D doll edition, including smoother local hider movement and aiming.

- `pet-hide-duel.html`: send and play together in a compatible desktop pet host.
- `pet-hide-duel-lan.zip`: extract and start the LAN launcher for browser play with uploaded 2D artwork; the hosting computer requires Node.js 22+.
- `SHA256SUMS.txt`: download checksums.

All 75 core/network/service tests and both 2D and 3D real hidden-host delivery, invitation, input and leave paths passed. The HTML includes full third-party notices and contains no private photos, character packs, or host installers.

Known limitation: opponent fragments visible through holes still follow network snapshots and may step. Physical two-computer play, native Windows startup and internet play are unverified. Both peers must use this version. 3D requires a compatible host and the player's own doll assets.
