# 躲好了吗？ · Pet Hide Duel

双人局域网躲猫猫对决，支持 2D 宠物与 3D 玩偶正面摆姿势。当前唯一维护版本为 **2.0.2**，游戏文件是 `躲猫猫对决.html`，无需 CDN。

[下载游戏与局域网完整包](https://github.com/ShunyuYao/pet-hide-duel/releases/latest) · [English](README.en.md) · [验证范围](docs/VALIDATION.md)

## 开始玩

**桌宠中一起玩**：两人连同一局域网，使用支持作品联机的桌宠。把 HTML 发给朋友，选择“发送并一起玩”；朋友打开作品并接受邀请。首次连接核对设备码并允许读取角色。双方选好初始姿势，点“带着它加入对决”和“我准备好了”。“仅分享”只发送作品；房主页面需要持续打开。

需要的宿主能力是 `character.getCurrent`、`sessions` 和对应授权；3D 另需 `character.getRealtime`。旧安装包可能不支持。此仓库仅分发游戏，不提供宿主安装包或宿主下载地址。

**普通浏览器**：下载 Release 的 `pet-hide-duel-lan.zip` 并解压。房主安装 Node.js 22+ 后，运行 `启动局域网.command`（macOS）、`启动局域网.cmd`（Windows），或 `node launch-server.cjs`。两人在浏览器打开终端显示的同网地址，上传 2D 透明 PNG/WebP，由房主创建房间，再分享房间码。房主保持服务运行。服务只用于可信局域网，不要暴露到公网。单独双击 HTML 不会自动建立双人联机。

## 玩法

- 大厅选择 2D 初始姿势，或拖动 3D 玩偶四肢后确认。初始姿势和大小入房后固定。
- 躲藏用 A/D、左右方向键或按钮移动；每次旋转 15°，冷却 1 秒。
- 射击点击墙面，或方向键瞄准、空格开枪。每轮 3 发子弹；准备 3 秒、射击 20 秒。
- 每人 100 血，命中扣 34；命中、用完子弹或超时换边。弹孔保留，整局最多 6 分钟。
- 双方点“再来一局”重开；断线暂停，30 秒未恢复判负；主动离开算认输。

3D 当前支持 `rat-doll-renderer` 数据 v2 的男女玩偶；不是通用模型导入器。确认后使用固定正面像素，显示、遮挡和命中共用同一轮廓。局内不发送完整 3D 资源。姿势保存在本作品的本地空间。仓库不包含照片或角色包。

## 当前边界

自己躲藏移动与准星已改为逐帧显示，并在松手后确认最终位置。**射击方看见的洞口角色碎片仍随联机快照刷新，可能明显跳动**，尚未完成这部分优化。与历史 HTTP / SDK v1 文件不混用，双方使用同一版本。

已验证本机两个隔离的真实桌宠进程。两台物理电脑、Windows 原生启动、防火墙差异和公网联机未验证，详见验证记录。

## 开发

Node.js 22+：

```sh
npm ci
npm run build
npm run test:public
npm start
```

`game/` 是游戏源码，`vendor/` 是随 HTML 打包的渲染组件，`server.cjs` 是可选的局域网服务。`build:check` 校验已提交的 HTML 与源码及许可一致。无需私有宿主即可构建、跑核心/网络/服务测试和启动浏览器服务。

真实宿主 E2E 需要另行持有可运行的宿主开发检出，显式设置 `PET_DUEL_HOST_REPO`。3D 测试还需 `PET_DUEL_PACKS_DIR` 指向含男女玩偶解包目录和 `rat-doll-male.zip` 的本地夹具目录；缺依赖会失败，不记为通过。完整命令与边界见 [验证说明](docs/VALIDATION.md)。
